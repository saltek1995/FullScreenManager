# FullScreenManager

FullScreenManager делает полноэкранные окна в Windows похожими на Spaces в macOS.

Когда окно разворачивается на весь экран, приложение создаёт для него отдельный рабочий стол и переносит его туда. После сворачивания, закрытия или выхода из полноэкранного режима окно возвращается обратно, а освободившийся рабочий стол удаляется.

## Что умеет

- создаёт отдельный рабочий стол для полноэкранного приложения;
- возвращает окно обратно после закрытия, сворачивания или выхода из полного экрана;
- подписывает рабочий стол названием открытого приложения;
- восстанавливает состояние и удаляет пустые рабочие столы после перезапуска;
- обрабатывает приложения, которые уже были открыты до запуска;
- работает из системного трея;
- может запускаться вместе с Windows.

## Установка

1. Скачайте `FullScreenManager.exe` из раздела **Releases**.
2. Запустите файл и подтвердите запрос Windows.
3. При необходимости включите автозапуск через значок приложения в трее.

Установка .NET и других компонентов не требуется.

## Системные требования

- Windows 11;
- 64-разрядная система.
