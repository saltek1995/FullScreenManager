# FullScreenManager

FullScreenManager делает полноэкранные окна в Windows похожими на Spaces в macOS.

Когда окно разворачивается на весь экран, приложение создаёт для него отдельный рабочий стол и переносит его туда. После сворачивания, закрытия или выхода из полноэкранного режима окно возвращается обратно, а освободившийся рабочий стол удаляется.

## Что умеет

- создаёт отдельный рабочий стол для полноэкранного приложения;
- возвращает окно обратно после закрытия, сворачивания или выхода из полного экрана;
- подписывает рабочий стол названием открытого приложения;
- восстанавливает состояние и удаляет пустые рабочие столы после перезапуска;
- обрабатывает приложения, которые уже были открыты до запуска;
- работает из системного трея;
- может запускаться вместе с Windows.

## Установка

1. Скачайте `FullScreenManager.exe` из раздела **Releases**.
2. Установите **.NET 8 Desktop Runtime (x64)**, если он ещё не установлен. При запуске Windows сама предложит перейти к его установке.
3. Запустите файл и подтвердите запрос Windows.
4. При необходимости включите автозапуск через значок приложения в трее.

Другие компоненты не требуются.

## Системные требования

- Windows 11;
- 64-разрядная система;
- .NET 8 Desktop Runtime (x64).

## Сборка

```powershell
.\build.ps1
```

Скрипт сначала запускает стандартный MSTest-проект из `tests`, затем публикует приложение в `dist`.

Для отдельного запуска проверок используется одна стандартная команда:

```powershell
dotnet test FullScreenManager.sln
```

## Диагностика

```powershell
.\FullScreenManager.exe --diagnose
```

Снимок реальных виртуальных столов, активных сессий и записей восстановления сохраняется в
`%LOCALAPPDATA%\FullScreenManager\diagnostics.json`.

## Инварианты управления Space

- одному HWND и одному созданному Space соответствует не более одной сессии;
- исходным для созданного Space может быть только обычный, неуправляемый рабочий стол;
- сессия удаляется из хранилища только после нескольких согласованных подтверждений отсутствия Space;
- записи о Space без активной сессии непрерывно сверяются с Windows и автоматически очищаются;
- полноэкранные окна непрерывно обнаруживаются на всех рабочих столах независимо от foreground и пропущенных событий изменения размера;
- проверка exclusive fullscreen сверяет координаты DWM и User32, поэтому не зависит от временной рассинхронизации при смене игрового разрешения.
